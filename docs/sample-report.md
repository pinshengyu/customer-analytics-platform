## 待驗證行動

- 先檢視高風險比例與人數較高的客群，結合近期購買紀錄規劃維繫方案。
- 比較客群總預測利潤與每人預測利潤，分別評估規模與客戶價值。
- 若最新季度觸發異常，依診斷來源下鑽檢查商品、交易通路與活動；歸因結果不等於因果證明。

## 定義與限制

- 所有分群分析使用僅由合格Train建立的分群中心及 LLM 客群名稱；預測快照逐季指派，歷史報表使用固定客戶對照；Cohort 不使用分群。
- 流失機率未另做校準；高風險門檻70%，測試分類門檻50%。
- CLV 是下一季度（2026Q1）利潤預測，允許負值，未折現；部署版本由15%驗證集決定。
- 營收淡色範圍來自內部測試誤差，未校準覆蓋率，不是90%信賴區間。
- 建議是待驗證的行動方向；目前專案未包含策略模擬，報告不宣稱已驗證ROI。
- 2023Q1為觀察暖身；2023Q2～2025Q3客戶季度快照按目標季度、CustomerID排序切70/15/15。跨界未到期標籤排除，同一客戶可跨季出現。
- 切分筆數（名義／實際使用／排除）：Train 47739/41381/6358；Validation 10230/6148/4082；Test 10230/10230/0
- 2025Q4獨立回測不參與選模；回測模型訓練至2025Q3，2026Q1部署模型加入回測季已知標籤重訓。
- 營收是季度彙總序列，11筆開發資料近似切為7/2/2季；獨立回測只有一筆，不能代表長期平均表現。
